# src/

Mã contract. Mô tả chi tiết từng thư mục, mục đích và luật phụ thuộc: **`docs/06-cau-truc-thu-muc.md`**.

Tóm tắt: `core/` là những gì mọi chi nhánh đều có và luôn bật; `modules/` chỉ chứa dịch vụ bật/tắt được theo chi nhánh (NET, IQR, Loyalty); `libraries/` là logic thuần; `interfaces/` là interface dùng chéo.
